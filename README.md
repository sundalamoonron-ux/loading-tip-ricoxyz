# Loading Screen Gold: A Tip in 200 Characters

One loading-screen tip, 200 characters or fewer, for stressed developers and AI coding agents — the agent finished the feature, the tests failed, and only one of you will remember what you both learned.

## The tip

> Loading tip: the agent finished the feature. The tests failed. You both learned something. Only one of you will remember it.

## How it works

Run `python3 main.py` — it validates the tip (one line, 1–200 characters, UTF-8) and writes it to `/output/entry.txt`.
